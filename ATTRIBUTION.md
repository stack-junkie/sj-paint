# Attribution

Stack Junkie Paint (SJ Paint) is an independent drawing editor inspired by modern Microsoft Paint. Its goal of matching the Microsoft Paint baseline remains unfinished; project-specific extensions follow that baseline. Microsoft Paint and Windows are Microsoft product names. This project is not affiliated with, endorsed by or sponsored by Microsoft.

The implementation uses independently written editing and rendering code and newly drawn icons. Microsoft executables, icon assets and model weights are not included. The initial reference, supported features and verification history are documented in [PARITY.md](PARITY.md).

[REA](https://github.com/morluto/rea) was used for static inspection of the reference application's executable resources. That inspection helped establish resource inventory; it does not establish behavioral equivalence.

The independently written `.paint` codec uses disposable files generated by Microsoft Paint 11.2605.81.0 and the public [mspaintlib format specification](https://github.com/setiri/mspaintlib/blob/master/PAINT-FORMAT-SPEC.md) as format references. No mspaintlib source is included. Support is limited to the tested full-canvas BGRA8/raw-DEFLATE layer and overlay variant, as documented in [PARITY.md](PARITY.md).

## Dependencies

The desktop application is built with [Electron](https://www.electronjs.org/), which includes Chromium and Node.js. Development and packaging use [Vite](https://vite.dev/) and [electron-builder](https://www.electron.build/). Browser verification uses [Playwright](https://playwright.dev/).

Dependencies retain their own licenses. Packaged distributions include `LICENSE.electron.txt` and `LICENSES.chromium.html`; retain those notices when redistributing the app. The dependency versions are recorded in `package-lock.json`.
