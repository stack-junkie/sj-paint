# Attribution

Stack Junkie Paint (SJ Paint) is an independent drawing editor inspired by modern Microsoft Paint. It does not claim exact feature or pixel parity. Microsoft Paint and Windows are Microsoft product names. This project is not affiliated with, endorsed by or sponsored by Microsoft.

The implementation uses independently written editing and rendering code and newly drawn icons. Microsoft executables, icon assets and model weights are not included. The initial reference, supported features and verification history are documented in [PARITY.md](PARITY.md).

[REA](https://github.com/morluto/rea) was used for static inspection of the reference application's executable resources. That inspection helped establish resource inventory; it does not establish behavioral equivalence.

The independently written `.paint` codec uses disposable files generated by Microsoft Paint 11.2605.81.0 and the public [mspaintlib format specification](https://github.com/setiri/mspaintlib/blob/master/PAINT-FORMAT-SPEC.md) as format references. No mspaintlib source is included. Support is limited to the tested full-canvas BGRA8/raw-DEFLATE layer and overlay variant, as documented in [PARITY.md](PARITY.md).

The independent TIFF codec follows the public [TIFF 6.0 specification](https://www.itu.int/itudoc/itu-t/com16/tiff-fx/docs/tiff6.pdf). Original grayscale and palette test fixtures were generated with Pillow/libtiff or a specification-based Python encoder, then independently decoded with Pillow/libtiff; their generator, version provenance and hashes are retained in test source. Pillow and libtiff are not bundled runtime dependencies.

## Dependencies

The desktop application is built with [Electron](https://www.electronjs.org/), which includes Chromium and Node.js. Development and packaging use [Vite](https://vite.dev/) and [electron-builder](https://www.electron.build/). Browser verification uses [Playwright](https://playwright.dev/).

Dependencies retain their own licenses. Packaged distributions include `LICENSE.electron.txt` and `LICENSES.chromium.html`; retain those notices when redistributing the app. The dependency versions are recorded in `package-lock.json`.

Project source code is provided under the [MIT license](LICENSE).

## Optional local AI assets

The independent worker implements the published U-2-Net/rembg preprocessing recipe. [U-2-Net](https://github.com/xuebinqin/U-2-Net) is by Xuebin Qin and contributors (Apache-2.0). The separately acquired U2Net and U2NetP ONNX conversions are distributed by [rembg](https://github.com/danielgatis/rembg) (adapter code MIT). Reviewed release metadata did not provide a separate per-weight license notice.

Object selection uses the separately downloaded [EfficientSAM tiny ONNX encoder and decoder](https://huggingface.co/yunyangx/EfficientSAM/tree/1cf49585c39567bfc49e991ab8eb31f491ad4877). The manifest records Apache-2.0 and pins both file digests. Legacy generation metadata refers to the pinned [SDXL component distribution](https://huggingface.co/diffusers/stable-diffusion-xl-1.0-inpainting-0.1/tree/115134f363124c53c7d878647567d04daf26e41e), with its OpenRAIL++ license and model card retained. Diffusion generation and fill are excluded from this release and new setup. Model licenses apply separately from this application's MIT license.

Object removal uses the author-published [MI-GAN ONNX pipeline](https://huggingface.co/andraniksargsyan/migan/tree/406830d0fa60666da0071c342ad2fbc8f30c5c64) by Picsart AI Research. Its authors publish an explicit [MIT weights license](https://github.com/Picsart-AI-Research/MI-GAN/blob/2b793c5ece43f4253e32d4afc257120a5deed6f5/LICENSE-WEIGHTS). The pinned model and license are acquired separately through managed setup.

Legacy metadata retains the four-channel UNet provenance from [SDXL base 1.0](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0/tree/462165984030d82259a11f4367a4eed129e94a7b), under OpenRAIL++, with the existing pinned CLIP encoders and corrected fp16 VAE. This component profile is recorded explicitly; it is not an exact copy of an upstream example checkpoint. Previously acquired assets retain license notices and the shared component model card. The linked base repository provides its own model card. Image creation, stickers and coloring pages are excluded from the released interface, bridge and new setup. Legacy metadata retains the [ColoringBookRedmond-V2](https://huggingface.co/artificialguybr/ColoringBookRedmond-V2/tree/0e67e0de2b603db085e525e7f6194b24dc60033d) attribution to artificialguybr under CreativeML OpenRAIL-M, but new setup does not offer or download that adapter.

Application archives do not include model weights or Python runtimes. Optional managed setup downloads pinned upstream artifacts after the user selects Install. The runtime includes CPython, ONNX Runtime, PyTorch, Diffusers, Transformers, Accelerate, NumPy, Pillow and their dependencies according to the selected profile. The pinned generation runtime also retains [OpenCV headless](https://pypi.org/project/opencv-python-headless/4.13.0.92/) as a dependency; existing runtime installations remain reusable. OpenCV uses Apache-2.0; its Python packaging uses MIT, and bundled third-party notices remain in the installed wheel. Artifact sources, byte sizes, SHA-256 digests and declared licenses are recorded in `electron/ai-assets.json`; installed packages retain their included license notices. The application uses the ISC-licensed `tar` package to extract the private Python distribution. Model identity, acquisition provenance and evaluation limits are recorded in `PARITY.md`.
